Docker preflight check

别等四分钟拉取超时后，才发现 Registry 根本不可达。

ForgeKit 默认 Preflight 检查源码目录、容器运行时、磁盘空间、计划文件和 Registry 连通性。失败项会阻止“假成功”，并给出可验证的下一步。

环境

Docker Engine 或 Podman

Podman 的 Docker CLI 兼容层会明确标记为实验性，不冒充稳定 Docker 支持。

资源

磁盘与源码目录

提前识别路径不存在、不可访问或构建空间不足。

网络

Registry 连通性

默认检查镜像仓库，不建议为了“绿灯”主动跳过。

结构化门禁

通过项、失败项和建议动作分别记录。

{
  "all_passed": false,
  "failed_count": 1,
  "checks": [{
    "name": "registry_connectivity",
    "status": "fail",
    "suggested_fix": "确认网络或使用受信任 Registry"
  }]
}
