MCP build tool

让 Agent 构建 Docker 镜像之前，先把检查和验证边界说清楚。

ForgeKit 提供结构化 MCP 工具：先识别项目、生成可审查计划、执行 Preflight，再构建镜像并显式验证容器和健康端点。它不会默认上传源码或修改系统配置。

当前安装边界

npm 尚未公开，使用已验证的 GitHub commit。

Node.js 18+；首次运行会下载和 clean build；写操作前先审查 Forge.md。

MCP 配置
{
  "mcpServers": {
    "forgekit": {
      "command": "npx",
      "args": ["--yes", "--package=github:CDUESTC-OpenAtom-Open-Source-Club/ForgeKit#f5fbc4e", "forgekit-mcp"]
    }
  }
}
不要跳过门禁

推荐的 Agent 指令应包含完整 Preflight 和运行验证。

检查当前项目并生成 Docker 交付计划；
运行完整 preflight（包括 Registry 连通性）；
只有全部必要条件满足后才构建；
构建后启动临时容器并验证 /health；
失败时返回证据、错误类别和验证步骤。
记录一次真实接入了解 Preflight
ForgeKitAgent 可调用，结果可复核。
